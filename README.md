# tiktokliveroblox


# TikTok Roblox Connector 🎮📱

Connect TikTok LIVE events directly into Roblox using Node.js.

---

# 📦 Requirements

Install the following first:

- Node.js
- Roblox Studio
- TikTok account with LIVE access

Download Node.js here:

https://nodejs.org/

---

# 🚀 Setup

Open CMD or Terminal:

```bash
mkdir tiktok-roblox
cd tiktok-roblox
```

Initialize project:

```bash
npm init -y
```

Install dependencies:

```bash
npm install tiktok-live-connector express
```

---

# 📂 Create `server.js`

Create a file named:

```plaintext
server.js
```

Paste your TikTok LIVE connector code inside it.

---

# ▶️ Start Server

Run:

```bash
node server.js
```

---

- Spawn Roblox avatars from comments
